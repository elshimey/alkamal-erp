# ERP الكمال للنقليات

نظام إدارة متكامل لشركة الكمال للنقليات: الأسطول، البوالص والرحلات، المبيعات والتحصيل، المصروفات، الصيانة، الرواتب، والمحاسبة بدفتر أستاذ واحد تُبنى منه كل التقارير.

وثائق التصميم (في ملفات المشروع): ملخص المتطلبات، نموذج البيانات والوحدات (الإصدار الثاني)، شجرة الحسابات.

## ما يحتويه الأساس الحالي

| الجزء | الحالة |
|---|---|
| واجهة ويب عربية من اليمين لليسار | ✓ |
| الدخول والجلسات وتغيير كلمة المرور | ✓ |
| الأدوار الأساسية (مدير النظام، المدير، المحاسب، السائق) والأدوار المخصصة بمصفوفة صلاحيات | ✓ |
| شجرة الحسابات وفق IFRS (115 حساباً) مع إضافة الحسابات الفرعية | ✓ |
| العملات (ريال، دينار كويتي)، رموز الضريبة، الفترات المحاسبية | ✓ |
| دفتر الأستاذ: القيد وسطره، وضوابط الترحيل داخل قاعدة البيانات | ✓ |
| المركبات مع إنشاء مركز التكلفة تلقائياً | ✓ |
| البوالص، العقود، الفواتير، المصروفات، الصيانة، الرواتب، التقارير، تطبيق السائق | الوحدات التالية |

### ضوابط دفتر الأستاذ (داخل قاعدة البيانات)

لا يمكن لأي شاشة أو استيراد تجاوزها ([drizzle/0001_ledger_integrity.sql](drizzle/0001_ledger_integrity.sql)):

- لا يُرحَّل قيد غير متوازن بالريال، أو بأقل من سطرين، أو بمبلغ صفر.
- لا ترحيل على حساب تجميعي أو موقوف.
- حسابات تكلفة التشغيل (5xxx) تتطلب المركبة كمركز تكلفة على السطر.
- عملة السطر يجب أن تطابق عملة الحساب إن كان له عملة (مثل صندوق الدينار).
- القيد المرحّل لا يُعدَّل ولا يُحذف؛ يُرجَع لمسودة أولاً، والفترة المقفلة تمنع الترحيل والإرجاع.

## التقنية

PostgreSQL · Next.js (TypeScript) · Drizzle ORM · Tailwind CSS · Vitest.

## التشغيل محلياً (للمطوّر)

```bash
cp .env.example .env          # عدّل رابط القاعدة إن لزم
docker compose up -d db       # أو استخدم PostgreSQL مثبتاً لديك
npm install
npm run db:setup              # إنشاء الجداول وزرع البيانات الأساسية ومدير النظام
npm run dev                   # http://localhost:3000
```

عند أول `db:setup` يُنشأ مستخدم مدير النظام باسم `ADMIN_LOGIN` (الافتراضي `admin`). إن تُركت `ADMIN_PASSWORD` فارغة تُولَّد كلمة مرور مؤقتة وتُعرض مرة واحدة في الطرفية؛ غيّرها من صفحة «حسابي» بعد الدخول.

### الأوامر

| الأمر | الغرض |
|---|---|
| `npm run dev` | التشغيل للتطوير |
| `npm run build` / `npm start` | البناء والتشغيل للإنتاج |
| `npm run db:generate` | توليد ترحيل جديد بعد تعديل `src/db/schema.ts` |
| `npm run db:setup` | تطبيق الترحيلات والتهيئة (آمن للتكرار) |
| `npm test` | الاختبارات؛ اختبارات قاعدة البيانات تعمل عند ضبط `TEST_DATABASE_URL` (تُمسح تلك القاعدة) |
| `npm run lint` / `npm run typecheck` | الفحص |

```
src/app/                    الشاشات

```
